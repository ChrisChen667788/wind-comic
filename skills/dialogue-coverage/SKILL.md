# 对话戏的镜头覆盖

对话戏最常见的失败不是拍得不好看,而是**观众分不清谁在对谁说话、谁站在哪边**。

## 守住轴线

- 两个说话的人之间连一条假想线,**所有机位都放在线的同一侧**。
- 越过这条线,观众会觉得两人突然交换了位置。真要越轴,必须先给一个镜头把机位「带」过去(跟着人物走过去,或者插一个正对轴线的镜头)。

## 覆盖的顺序

按从远到近准备镜头,剪辑时才有选择:

1. **建立镜头**:两人同框的全景或中景,交代空间关系和彼此的距离。
2. **过肩镜头**:从 A 的肩后拍 B,再反过来。前景的肩膀提醒观众另一个人还在。
3. **单人近景**:情绪升级时切到单人,去掉对方,让观众只看这一张脸。
4. **反应镜头**:听的人的表情。**关键台词之后必须有**。

## 视线匹配

- A 看向画面右侧,B 就要看向画面左侧,两人的视线才会在剪辑后「对上」。
- 两个单人镜头的**机位高度和景别要对称**,除非你想表达两人地位不对等。

## 用景别表达张力

- 冲突升级时,**景别逐步收紧**:全景 → 过肩 → 近景 → 特写。
- 一方占上风时,给他更大的画面面积、更低的机位。
